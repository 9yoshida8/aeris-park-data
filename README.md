# エアリススケートパーク太田 — 開示データと市民提言（公開版）

太田市の公文書開示制度で取得した日次利用データを一市民が分析し、
より良いパーク運営を提案するページです。

**公開ページ:** https://9yoshida8.github.io/aeris-park-data/

## この提案の、四つの約束
1. **戻すだけ** — 新しい特権ではなく、市が半年間実証した無料期間への復帰
2. **誰の負担も増やさない** — 登録制はそのまま、市外の料金もそのまま
3. **データで検証する** — 効果は日々の記録が証明
4. **「空いていて良い」も守る** — 目指すのは満員ではなく「行けば誰かはいる」

## データの要点
- 市内利用者が0人の日：無料期間 1%（179日中2日）→ 有料化後 22%（年82日）
- 利用者が誰もいない日：年46日（営業日の13%）

## 提案（三本柱）
1. 市民無料期間の延長（市内在住・在勤・在学／登録制）
2. 夏期の早朝開放（熱中症対策）
3. 月例ボウルイベント（協会共催）

## データ出典
太田市 公文書開示（2026年6月・第1回）：スケートパーク日次集計表ほか。
掲載している数値と算出方法は、開示文書そのもので検証できます。

## アクセス解析について
このページは GoatCounter（オープンソース・Cookie不使用・個人を特定しない計測）を使用しています。
