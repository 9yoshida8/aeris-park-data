# エアリススケートパーク太田 — 開示データ分析と再活性化提言（公開版）

太田市の公文書開示制度で取得した日次利用データ（2024年6月〜2026年6月）を一市民が分析し、
より良いパーク運営のための四つの施策を提案するページです。

**公開ページ:** https://9yoshida8.github.io/aeris-park-data/

## 主な発見
- 有料化後、利用者は無料期の約4割に減少（同月比較）
- 市内利用者が0人の日：無料期 1%（179日中2日）→ 有料化後 22%（年82日）
- 市内料金の年間収入は約60万円（収入全体の2割弱）
- 減免イベント開催日は平常日の4〜6倍（毎回50〜81人）を集客

## 提案（四本柱）
1. 市内在住・在勤・在学者の利用無料化（市外1.5倍は維持）
2. 夏期の早朝開放（猛暑日対応・無人ゲートのため追加人件費ほぼゼロ）
3. 月例ボウルイベント（協会共催・観客動線つき）
4. スポンサー／ネーミングライツ財源の本格化

## データ出典
- 太田市 公文書開示（2026年6月22日付請求）：利用実績集計表・日次集計表・イベント実績一覧表・歳入資料
- 気象：Open-Meteo（太田市・日最高気温／降水量）
- 詳細な算出方法・留保はページ末尾「出典と留保」参照
